# Пакеты ТВ-клиента

Сборка: `python build.py` → появятся файлы в `dist/`.
Ни Tizen Studio, ни webOS CLI, ни Android SDK для сборки не нужны.

Внутри всех пакетов лежит одно и то же — `index.html`, `app.js`, `app.css`
из папки `tvapp/`. Отличаются только манифесты.

---

## Что реально можно поставить и куда

| Платформа | Способ | С флешки |
|---|---|---|
| Android TV, Google TV, Яндекс ТВ, Hisense на Android, приставки | APK | **да** |
| Samsung (Tizen) | браузер ТВ, либо `.wgt` в режиме разработчика | нет |
| LG (webOS) | браузер ТВ, либо `.ipk` в режиме разработчика | нет |
| Hisense VIDAA, Roku | только браузер (если есть) и Media Station X | нет |

**Самый простой путь для любого телевизора с браузером** — открыть
`sapkeflykino.ru/tvapp/` и положить в закладки. Ничего устанавливать не надо,
интерфейс наш целиком.

---

## Android

Пересобирать APK **не требуется**: приложение представляется своим
User-Agent `SAPKEFLYKINO-TV`, и nginx отдаёт ему `302` на `/tvapp/`.
Уже установленные копии сами перешли на новый клиент.

Если однажды понадобится собрать заново (например, сменить стартовый адрес
внутри приложения) — проект лежит в `Projects/кино/kinotv-webview`, но для
сборки нужны JDK и Android SDK, которых сейчас на машине нет.

## Samsung (Tizen), файл `.wgt`

Файл собран, но **не подписан**, а без подписи телевизор его не установит.
Подпись выдаётся только в Tizen Studio и привязывается к конкретному
телевизору, поэтому автоматизировать её нельзя. Порядок:

1. На телевизоре: «Приложения» → ввести `12345` на пульте → включить
   «Режим разработчика», вписать IP компьютера, перезагрузить ТВ.
2. На компьютере: Tizen Studio → Certificate Manager → создать Samsung
   Certificate, при создании подключить телевизор (он подставит свой DUID).
3. `tizen package -t wgt -s <профиль> -- dist/sapkeflykino-tv.wgt`
4. `tizen install -n sapkeflykino-tv.wgt -t <имя ТВ>`

Срок жизни сертификата — 60 дней, потом установку надо повторять. Это
ограничение Samsung, обойти его нельзя.

## LG (webOS), файл `.ipk`

Подпись не нужна, но нужен режим разработчика:

1. Завести аккаунт на `webostv.developer.lge.com`.
2. На телевизоре установить из магазина приложение **Developer Mode**,
   войти в аккаунт, включить Dev Mode и Key Server.
3. На компьютере: `npm i -g @webos-tools/cli`
4. `ares-setup-device` — добавить телевизор (IP, порт 9922, passphrase из
   приложения на ТВ).
5. `ares-install --device <имя> dist/ru.sapkeflykino.tv_1.0.0_all.ipk`

Сессия разработчика живёт около 50 часов, продлевается в том же приложении
на телевизоре одной кнопкой.

## Media Station X

Ставится из официального магазина Samsung и LG, поэтому ничего подписывать и
включать не нужно. В её настройках вбивается один адрес:

    sapkeflykino.ru/msx/start.json

Важно понимать ограничение: MSX **не запускает наше приложение**. Она рисует
свой интерфейс по нашему JSON и играет видео родным плеером телевизора. То
есть каталог и просмотр — наши, а внешний вид — её. Свой дизайн там
невозможен ни у кого, включая другие кинотеатры в этом же списке.
