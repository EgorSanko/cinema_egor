sapkeflykino — инструкция
==========================

ЧТО В АРХИВЕ
------------
- movie-website.zip     — исходники сайта (Next.js) → sapkeflykino.ru
- kinotv-app-mobile.zip — исходники мобильного приложения (Expo / React Native)
- sapkeflykino.apk      — готовый APK для установки на Android


ЧТО УСТАНОВИТЬ НА КОМПЬЮТЕР
---------------------------
1. Node.js 20+          https://nodejs.org           (обязательно)
2. VS Code              https://code.visualstudio.com (редактор кода)
3. Git (по желанию)     https://git-scm.com


КАК ОТКРЫТЬ ПРОЕКТ
------------------
1. Распаковать sapkeflykino-full.zip куда угодно (например на рабочий стол).
2. Распаковать movie-website.zip и kinotv-app-mobile.zip в отдельные папки.
3. Открыть VS Code → File → Open Folder → выбрать нужную папку.


================================================================
САЙТ (movie-website) — Next.js
================================================================
Открыть терминал в папке movie-website и выполнить:

    npm install
    npm run dev

Откроется http://localhost:3000 — там и работаем.

Продакшн билд:
    npm run build
    npm start


================================================================
МОБИЛЬНОЕ ПРИЛОЖЕНИЕ (kinotv-app-mobile) — Expo
================================================================
1. Установить на свой телефон "Expo Go" из Google Play / App Store.
2. В папке kinotv-app-mobile открыть терминал и выполнить:

    npm install
    npx expo start

3. Отсканировать QR-код камерой (iOS) или через Expo Go (Android).
   Приложение запустится на телефоне, код меняется → всё обновляется в реальном времени.

УСТАНОВКА ГОТОВОГО APK
================================================================

2. Открыть файл → разрешить "Установку из неизвестных источников".
3. Установить.
